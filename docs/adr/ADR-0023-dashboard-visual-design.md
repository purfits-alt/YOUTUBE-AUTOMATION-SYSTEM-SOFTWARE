# ADR-0023: Dashboard visual design — tokens, inline icons, own Lottie animations

**Status:** Accepted (owner request during Phase 2, 2026-11-08: "premium dashboard, icons, animation and Lottie") · **Date:** 2026-11-08 · **Deciders:** Owner, Claude Code

## Context
The owner asked for a premium-looking dashboard with icons, animation and Lottie. ADR-0006 named Tailwind + shadcn/ui + Recharts. Phase 2 needed a small, fast, accessible shell that runs well on an 8 GB PC.

## Options considered
1. **Tailwind tokens + hand-built components + inline SVG icons + small SVG charts + lottie-web (light player) with our own animations** (chosen)
2. shadcn/ui (Radix) + an icon package + Recharts + downloaded LottieFiles animations
3. A commercial UI kit / premium animation packs (rejected: paid, CLAUDE.md "never add a paid dependency")

## Decision
- **Look:** colour tokens in CSS variables (light/dark), an always-dark "studio" sidebar, gradient page heroes, cards with soft depth, avatars, badges with icon + text. Inter (OFL-1.1) is bundled, so text renders the same on every PC and in visual snapshots.
- **Icons:** a small inline SVG set (`components/icons.tsx`), no icon dependency.
- **Charts:** small SVG components (sparkline, area chart with a screen-reader table, ring gauge). Recharts stays an option for Phase 13 analytics.
- **Motion:** CSS only (rise-in, stagger, line draw, ring fill, bar grow, Emergency Stop pulse), plus number count-up. Everything is switched off by `prefers-reduced-motion`.
- **Lottie:** `lottie-web` 5.13 light SVG player (MIT), loaded lazily (own chunk, ~47 kB gzip) so first paint is not delayed. The animations are **our own artwork**, generated by `tools/gen_lottie.py` (studio orb, empty state, success check), so there is no third-party licence to track. With reduced motion the final frame is shown still.
- Dialogs use the native `<dialog>` element instead of Radix. shadcn/ui is not used.

## Free-tier status
Free. Introduces no paid dependency ✔ (lottie-web MIT, @fontsource-variable/inter OFL-1.1, Tailwind MIT).

## Licences
MIT / OFL-1.1. The Lottie JSON files are original and MIT like the repo.

## Consequences
- Accessibility stays a hard gate: axe (WCAG 2.2 AA) runs on all 31 routes in light and dark, with 0 serious/critical allowed.
- Visual snapshots run with reduced motion for stable pixels.
- ADR-0006's shadcn/ui and Recharts are replaced as described; FRONTEND_SPECIFICATION's stack line is updated.
